This is a repository filled with the tutorials from the Rustbook.
You can find the Rustbook here at: https://doc.rust-lang.org/book/title-page.html

Individually these scripts aren't really suitable for use in projects unless you know the context of them and their use cases.
I've tried to document each one with notes in comment form to help contextualise them.

If you're interested in the basics of Rust, I really recommend trying these tutorials for yourself. They're a lot of fun!
